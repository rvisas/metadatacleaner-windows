# Support

## Where to get help

- **Bug reports and Windows-specific feature requests:** open an issue using
  the templates in `.github/ISSUE_TEMPLATE/`.
- **Security problems:** use GitHub's private vulnerability reporting, as
  described in [`SECURITY.md`](SECURITY.md). Do not open a public issue.
- **Upstream application behavior:** report it to the
  [upstream project](https://gitlab.com/metadatacleaner/metadatacleaner), since
  this repository is an unofficial Windows port.
- **Installation, updates and packaging:** report those here.

## What to include

- Metadata Cleaner version and Windows version.
- The file type involved and whether the file is synthetic or private.
- Exact reproduction steps.
- Logs or screenshots with personal information removed.

## Scope

This is a volunteer project with one maintainer. There is no guaranteed response
time or commercial support. Security reports are prioritized over feature
requests. Do not send private files; create a synthetic sample when possible.
