# Code signing policy

**Free code signing provided by [SignPath.io](https://about.signpath.io),
certificate by [SignPath Foundation](https://signpath.org).**

This policy covers the Windows build published from
[`rvisas/metadatacleaner-windows`](https://github.com/rvisas/metadatacleaner-windows).
The project is an unofficial Windows port of Metadata Cleaner and is not
affiliated with the upstream maintainers.

## Signed artifacts

Subject to approval by SignPath Foundation, every production release signs:

- `MetadataCleaner.exe`, the native launcher;
- `MetadataCleaner-<version>-windows-x64-setup.exe`, the Inno Setup installer;
- `unins000.exe`, the uninstaller generated by Inno Setup.

Bundled third-party binaries (GTK, Python, exiftool, ffmpeg and their DLLs)
retain their own signatures and licenses. They are dependencies, not artifacts
built by this project.

## Build provenance

- Releases are built by GitHub Actions from a tag in the public repository.
- The build workflow is [`.github/workflows/release.yml`](.github/workflows/release.yml).
- The payload is assembled from the pinned upstream source tree plus the
  documented patches in [`patches/`](patches).
- Unsigned artifacts are uploaded before the signing request, so a missed
  approval can be retried without rebuilding.
- SignPath verifies the trusted build system and the artifact origin before
  signing.
- Every production signing request requires manual approval by an approver.

## Team roles

This is currently a single-maintainer project; the same person holds each role
until additional maintainers are added.

| Role | Member | Responsibility |
|---|---|---|
| Authors / committers | [@rvisas](https://github.com/rvisas) | Modify the source code and build scripts |
| Reviewers | [@rvisas](https://github.com/rvisas) | Review changes proposed by non-committers |
| Approvers | [@rvisas](https://github.com/rvisas) | Approve each production signing request |

All roles use multi-factor authentication for GitHub and SignPath access.
Changes from outside contributors are reviewed before merge; release tags are
created only from reviewed commits.

## Privacy

See [`PRIVACY.md`](PRIVACY.md). The application processes files locally and
does not upload their contents. Its only network operation is the optional
GitHub release check described in the privacy policy.

## Verification

Users can verify a signed installer with:

```powershell
signtool verify /pa /v .\MetadataCleaner-<version>-windows-x64-setup.exe
Get-AuthenticodeSignature .\MetadataCleaner-<version>-windows-x64-setup.exe |
  Format-List Status, StatusMessage, SignerCertificate
```

The expected signer is **SignPath Foundation**. SHA-256 sidecars are also
published with every release; verify both.

## Changes

This policy is versioned with the source. Material changes to the signed
artifacts, build workflow, roles or privacy practices must be reviewed and
committed before the next signing request.
