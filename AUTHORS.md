## Upstream

This is an unofficial port of **Metadata Cleaner**, maintained upstream at
<https://gitlab.com/metadatacleaner/metadatacleaner>. The upstream contributors
own the original application, name and artwork. The port keeps the upstream
source tree and adds the Windows launcher, packaging and documented patches.

The upstream project is not affiliated with this port and has not endorsed it.

## Third-party components

The installer includes third-party open-source components, including GTK,
libadwaita, PyGObject, Python, mat2, poppler, exiftool and ffmpeg. Each
component keeps its own copyright and license; see `LICENSES/` and the
component documentation.
